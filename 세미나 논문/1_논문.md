
## 0. 논문
- Learning from Oblivion: Predicting Knowledge Overflowed Weights via Retrodiction of Forgetting" (CVPR 2026 Highlight)

## 1. 요약
- **더 나은 성능을 내는 사전 학습된 가중치(Pre-trained weights)를 효율적으로 얻는 새로운 방법론**을 다루고 있습니다
- 데이터를 줄일 때 나타나는 '망각의 패턴'을 역추적(Retrodiction)하여, 추가 데이터 없이도 더 뛰어난 성능을 가진 사전 학습 가중치를 합성해내는 새로운 방법론

> [!이해]
> 망각 : 딥러닝 모델에서 학습에 쓰이는 데이터를 줄였더니, 모델이 기존에 알고 있던 정교한 패턴이나 특징을 까먹고 잃어버리는 현상
> 망각을 측정하기 위해 알고리즘이 수학적으로 자동 계산한다. (메타 러닝)

## 2. 문제 정의
- 현대 딥러닝에서는 방대한 데이터로 미리 학습된 가중치를 활용하는 것이 기본입니다.
    
- 그렇다면 "주어진 데이터셋보다 훨씬 더 많은 지식을 담고 있는(오버플로우된) 더 우수한 사전 학습 가중치"를 어떻게 얻을 수 있을까요? 데이터를 무한정 늘리는 것만으로는 비용과 한계가 있습니다.

## 3. 아이디어
- 연구진은 **데이터를 점진적으로 줄여가며 미세조정(Fine-tuning)을 하면 일종의 '구조화된 망각(Structured Forgetting)' 현상이 발생**한다는 점에 주목했습니다.

- 데이터를 줄여가며 잊어버리는 과정을 모델링하고, 이를 역으로 추적(Retrodiction, 역방향 예측)하면 마치 **훨씬 더 큰 데이터셋으로 학습한 것과 같은 효과**를 낼 수 있다는 것입니다.

- 데이터셋 크기를 점점 줄여가며 미세조정한다.
- 망각의 속도가 줄어드는 일정한 패턴과 규칙(구조화된 망각)이 데이터로 남는다.

> [! 이해]
> 비유 : 시간을 거슬러 올라가는 가속도 예측
> 즉, 데이터를 의도적으로 줄이면서 생기는 망각의 가속도를 예측하면, 
> 실제로 성능이 뛰어난 모델(가중치)를 직접 만들 수 있다.


## 4. 구현 
- 위 과정을 통해 얻은 가중치 :  **KNOW (KNowledge-Overflowed Weights):** 통제된 망각 과정을 통해 합성된, 지식이 풍부하게 확장된 가중치입니다.
    
- 위 과정을 구현한 모델 : **KNOWN (KNowledge-Overflowed Weights Nowcaster (forcast보다 더 짧은 미래)):** 가중치가 진화하는 일반적인 패턴을 학습하고, 더 나은 일반화 성능을 가진 향상된 가중치를 예측해 주는 하이퍼 모델(Meta-learning 기반)입니다.
- 단순한 MLP로 구현되었다.
- 이 모델이 망각 패턴을 자동으로 학습(메타 러닝)한다.
- 학습이 끝나면 KNOWN이 알아서 가중치가 나아가야 할 반대 방향을 계산하고, 최종적으로 성능이 향상된 가중치를 만들어 낸다.
- 아래 3가지를 수행하는 모델이다.
	- 망각 패턴 분석
	- 방향 계산
	- 새로운 가중치 합성

## 5. 성능
- 다양한 데이터셋과 신경망 아키텍처에서 실험한 결과, 단순한 미세조정(Naive fine-tuning)이나 기존의 단순 가중치 예측 방법보다 **다운스트림(하위) 태스크에서 훨씬 뛰어난 성능**을 보여주었습니다.
    
- 즉, 모델이 '무언가를 잊어버리는 과정'을 역으로 분석하여 오히려 모델의 지식과 성능을 극대화할 수 있다는 새로운 관점을 제시한 논문입니다.

> "다운 스트림 태스크"
> **"실제 응용 시험 / 특정 직무 실무"**  
> 기초 지식을 갖춘 모델을 가져와서 **내가 실제로 풀고 싶은 특정 문제**에 맞춰 적용하거나 미세조정(Fine-tuning)하는 단계입니다.
> 범용적으로 먼저 학습시켜 놓은 모델을 가져와서, 우리가 실제로 해결하고자 하는 구체적인 목적/문제에 적용하는 작업
-

> "업 스트림 태스크"
> - **"기초 체력 키우기 / 기초 공부"**
> 모델에게 방대한 양의 일반적인 데이터를 학습시켜 기본 지식과 감을 익히게 하는 단계입니다. (예: 인터넷의 수많은 글이나 이미지를 다 읽고 기본 패턴을 익히는 '사전 학습(Pre-training)')



## 6. Q
근데 역추적을 한다고 해도 선형적이거나 어느정도 예측가능한 곡선 형태면 모르겠는데 완전 비선형이면 우리가 예측할 수 있는 것은 망각을 진행했을 때의 데이터셋의 범위 내에서 밖에는 안될것같은데?

### 1. 비선형 곡선을 알아서 피팅하는 '메타 모델(KNOWN)' 사용

수학 공식으로 단순 직선을 그리는 게 아니라, 비선형적인 가중치 변화 궤적(Weight Trajectory) 자체를 학습할 수 있는 하이퍼 모델(KNOWN)을 도입했습니다.

- 비선형적인 궤적이라도 데이터셋 크기 변화($100\% \rightarrow 80\% \rightarrow 60\% \rightarrow 40\%$)에 따른 가중치 이동 경로를 신경망(Neural Network)에 학습시키면, 신경망 특유의 **비선형 매핑 능력**을 통해 복잡한 곡선 형태의 궤적을 추정할 수 있습니다.
    
- 즉, "선형 외삽"이 아니라 "비선형 궤적 추정(Trajectory Retrodiction)"을 수행하도록 메타 학습을 시킨 것입니다.
    

### 2. 가중치 공간의 'Local Smoothness (국소적 매끄러움)' 성질 활용

딥러닝의 전체 파라미터 공간은 비선형이지만, **충분히 잘 훈련된 사전 학습(Pre-trained) 가중치 근처의 아주 작은 구역(Local Region)으로 한정해서 보면 손실면(Loss Landscape)이 비교적 매끄럽고 안정적인 형태**를 띱니다.

- 무에서 유를 창조하듯 아무 가중치나 만들어내는 것이 아닙니다.
    
- 이미 대규모 데이터로 잘 정렬된 사전 학습 가중치 인근에서 **아주 미세하게 망각을 일으키며 궤적을 관찰**하기 때문에, 손실면이 갑자기 폭발하거나 튀지 않고 예측 가능한 범위 내의 곡선을 유지하게 됩니다.
    

### 3. '무한한 확장'이 아닌 '유효 범위 안에서의 오버플로우'

말씀해주신 지적처럼, 이 방법 역시 데이터셋을 100%$에서 1000%로 10배 폭발시키는 것"은 불가능합니다. 외삽(Extrapolation)의 한계 때문에 너무 멀리 가면 비선형 오차가 커져서 모델 성능이 오히려 망가지게(Collapse) 됩니다.

따라서 논문에서 말하는 '지식 오버플로우(Knowledge Overflow)'는 무한대의 지식을 만드는 게 아니라, **가지고 있는 데이터셋의 한계선 직전 혹은 살짝 넘어선 유효 범위(Local Neighborhood) 내에서 최상의 성능을 내는 가중치 지점**을 찾아 합성해내는 것입니다.
